# KCS Integrations — Integration Plane

This repository is the mechanical integration plane.

It connects independently developed systems through explicit capability contracts, adapters, routing, identity, provenance propagation, failure isolation, and integration tests.

It does not determine whether a composition is emergent intelligence.

## Core invariant

Integration must not silently manufacture evidence of intelligence.

An interaction between systems is an observed interaction. It is not automatically an emergent capability.

The Architecture Plane owns canonical system identity. The Experimental Plane defines controls, compositions, experiments, measurements, replication, and qualification.
